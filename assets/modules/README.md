# Captures des modules

Captures d'écran affichées dans la section « Modules en action ». Chaque image est rognée
par le haut (`object-position: top`, ratio 16:10) sur la carte et dans la fiche détaillée.

## Fichiers utilisés (noms exacts)

| Module                | Fichier            | Source           |
|-----------------------|--------------------|------------------|
| Facturation           | `facturation.png`  | Vander · Facturation |
| TakeOff               | `takeoff.png`      | Vander · TakeOff |
| Intégration Dynamics  | `dynamics.png`     | Dynamics 365 — Documents à soumettre |

### En réserve (non affiché)

- `dynamics-changements.png` — 2e capture Dynamics (onglet Changements). Disponible si on veut
  changer la vignette Dynamics ou afficher une galerie dans la fiche.

## Recommandations

- **Format** : PNG, ratio **16:10**, idéalement **1600 × 1000 px**. Garde l'info importante en haut.
- **Poids** : vise < 400 Ko par image (compresse-les au besoin, ex. squoosh.app).
- **Confidentialité** : masque toute donnée réelle de client (noms, montants, numéros) avant publication.

## Ajouter un module

Pour réafficher un module retiré (Estimation, Échéancier, Réquisition), dépose sa capture ici
et je rebranche la carte correspondante dans `index.html`.
