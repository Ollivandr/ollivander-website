# Assets — logos Vander

Logo « Ov » ornementé de la suite **Vander** (détouré à fond transparent).

| Fichier                 | Usage |
|-------------------------|-------|
| `vander-logo.png`       | Logo **blanc** (365×246, transparent) — pour fonds **sombres** (le site). |
| `vander-logo-blue.png`  | Logo **bleu de marque** — pour fonds **clairs** (courriels, documents, signature). |
| `favicon.png`           | Icône d'app (180×180) : carré bleu dégradé + logo blanc. Favicon + apple-touch-icon. |

- La compagnie reste **Ollivander** ; **Vander** est la suite logicielle.
- Pour régénérer : scripts `detour.py` (détourage depuis l'artwork source) et `recolor.py`
  (recoloration) — conservés hors du dépôt (dossier scratchpad de la session).

Voir aussi [`modules/`](modules/) pour les captures des modules.
